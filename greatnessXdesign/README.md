# Greatness by Design — Publishing + Commerce Package

Deployable static site with Stripe Checkout through Netlify Functions.

Included:
- Cinematic responsive homepage
- Greatness by Design logo, CEO portrait, and 1:1 hero artwork
- Digital product storefront
- Three included PDF products
- Stripe-hosted one-time checkout
- Server-side Stripe secret handling
- Paid-session verification before delivery
- Purchase success and cancellation pages
- Journal/blog
- About/vision page
- Privacy and terms pages
- PPC/advertising placement areas
- SEO description, robots.txt, sitemap.xml, favicon
- Mobile navigation and responsive CSS

Before launch, read `COMMERCE_SETUP.md`.

You must create the Stripe products/prices and add the four Netlify environment variables. The package intentionally does not contain a Stripe secret key.

Also replace the example domain in `sitemap.xml`, add your verified advertising publisher entry/code, and review the privacy/terms language for the services you actually use.
